# Reference Resources

Reference materials support the syllabus; they do not define it.

The current project contains user-provided resources including books on:

- pattern recognition / machine learning (Bishop);
- engineering mathematics (Asadi; Stroud; Bird; Potter);
- finite element solid mechanics (Zienkiewicz & Taylor);
- engineering statics / vector mechanics;
- Python programming (Fluent Python).

## Reference-use rule

Before assigning a chapter or page range, verify that it directly supports the active official topic or an explicitly opened foundation bridge. Record the mapping rather than studying a textbook sequentially by default.

Exact chapter/page mappings should be added after searching the relevant book for the active topic.
